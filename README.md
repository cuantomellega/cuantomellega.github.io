# ¿CuántoMeLlega?

Calculadora gratuita para saber cuántos pesos mexicanos te llegan cuando te pagan en dólares (Upwork, Deel, transferencias, etc.), considerando comisiones y tipo de cambio.

👉 https://cuantomellega.github.io/

**Aviso:** los resultados son una estimación. No es asesoría financiera ni fiscal; las comisiones y el tipo de cambio pueden cambiar. Verifica siempre con tu proveedor.

¿Encontraste un error o una comisión desactualizada? Repórtalo en [Issues](https://github.com/cuantomellega/cuantomellega.github.io/issues).
