Avisos legales y privacidad / Legal notices and privacy
Analítica sin cookies y con panel privado: la dirección IP se procesa de forma temporal y se guardan datos técnicos agregados, no lo que escribes en la calculadora (Política de privacidad de GoatCounter). El tipo de cambio se consulta en frankfurter.dev y, si falla, open.er-api.com.

Cookie-free analytics with a private dashboard: the IP address is processed temporarily, and aggregate technical data is stored, not what you type in the calculator (GoatCounter privacy policy). The exchange rate comes from frankfurter.dev and, if that fails, open.er-api.com.

Las fuentes se cargan desde Google Fonts. Esa solicitud envía a Google datos técnicos, como la dirección IP y el agente de usuario (Privacidad de Google Fonts).

Fonts load from Google Fonts. That request sends Google technical data, such as the IP address and the user agent (Google Fonts privacy).
